A program that writes one image summing up Monday 23 November 2026's world
news to `/output/entry.png` — 37 stories across 7 regions, drawn as a
newspaper front page with original flat-vector graphics.

Headlines: COP31 collapses with no deal in Antalya · NATO meets on Monday
over Poland · a Russian corvette sinks off Libya · Schumer faces a
leadership fight · Asia moves to prop up stocks · Wall Street's AI rout.

Run it with Node 22: `node main.ts`. No network, no dependencies, standard
library only. It creates `/output` when missing and copies `entry.png` there,
checking the PNG magic bytes and logging the file's sha256.

Entry for the make.fun bounty
[Sum up 23 November's world news in one image](https://make.fun/bounty/news-image-20261123).
Strict 23-Nov-only dating: every story was first reported on 23 November
2026, and the DATE CHECK box on the page lists earlier stories that were
deliberately left out.
